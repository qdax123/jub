# 剧本字幕核对工具（最终完善版）使用说明

## 一、工具简介

本工具是一个**纯本地运行**的网页应用，用于核对剧本台词与字幕文本之间的一致性。  
它能够自动提取剧本中的台词（支持“人物名：台词”格式），并与字幕逐句比对，识别缺失短语和多余字幕行，帮助用户快速定位差异。

**核心特点：**

- ✅ 零依赖：无需联网，无需安装任何软件，双击 HTML 文件即可使用。
- ✅ 智能匹配：短词（≤2字）采用严格边界匹配，长词采用灵活包含匹配。
- ✅ 直观展示：按行高亮显示匹配/缺失状态，并生成字幕覆盖情况表格。
- ✅ 本地持久化：无后端，所有数据仅在当前页面内处理，不会上传。
- ✅ 安全防护：已禁用右键菜单和常见控制台快捷键（详见第六节）。
- ✅ 悬浮二维码窗口：右下角展示二维码占位图，可替换为真实二维码。

---

## 二、快速开始

1. 将提供的 HTML 代码保存为 `subtitle-checker.html`。
2. 双击该文件，使用任意现代浏览器（Chrome、Edge、Firefox、Safari）打开。
3. 在左侧“剧本原文”文本框粘贴剧本内容，格式为：
人物名：台词内容

text
例如：
张三：今天天气真不错。
李四（笑）：是啊，我们出去走走吧。

text
4. 在右侧“字幕文本”文本框粘贴字幕内容，每行一句，例如：
今天天气真不错。
是啊，我们出去走走吧。

text
5. 点击 **“🔍 核对差异”** 按钮，下方将显示核对结果。

其他操作：
- **📋 仅提取台词**：只提取剧本中的台词部分，不进行比对。
- **🗑️ 清空**：清空两个文本框和结果区域。

---

## 三、输入格式说明

### 3.1 剧本原文

- 支持格式：`人物名：台词内容`（冒号可以是中文`：`或英文`:`）。
- 人物名可以包含括号说明，如 `张三（激动）：...`。
- 自动忽略以下内容：
- 以 `▲`、`△` 开头的标记行。
- 以“人物：”、“时间：”、“地点：”、“场景：”等元信息开头的行。
- 集数/场景编号行（如“第一集 内景 日”）。
- 若某行没有冒号，但符合“人物名：台词”规则，则不会被提取为台词。

### 3.2 字幕文本

- 每行视为一句字幕。
- 自动去除行首尾空格，忽略空行。
- 字幕内容无格式要求，可以是纯文本。

## 四、核对逻辑说明

### 4.1 短语拆分

每条台词按标点符号（，。！？；：、,.!?;:）拆分为多个短语，每个短语独立进行匹配。

### 4.2 匹配规则

- **短词（规范化后长度 ≤2 个字符）**：  
必须在字幕文本中以独立形式出现，前后不能紧邻中文字母数字字符，避免误匹配（如“是”不会匹配“是否”）。
- **长词（长度 >2 个字符）**：  
只要在字幕文本中出现即可，允许部分包含关系，提高容错率。

### 4.3 结果判定

- **剧本台词完整匹配**：所有短语都在字幕中找到 → 该行标记为绿色（✅ 匹配）。
- **剧本台词缺失短语**：部分或全部短语未找到 → 该行标记为红色（❌ 缺失），并列出缺失的短语。
- **字幕行覆盖判断**：  
每条字幕行会尝试匹配所有剧本短语。若某行字幕没有匹配到任何剧本短语，则标记为**多余行**（⚠️ 黄色），并在表格中显示。

整体状态会显示在结果顶部：
- ✅ 完全匹配：所有剧本台词完整找到，且无多余字幕行。
- ⚠️ 部分匹配：剧本台词全部匹配，但存在多余字幕行。
- ❌ 不匹配：有剧本台词缺失短语，并列出所有缺失片段。

## 五、结果展示说明

### 5.1 剧本台词逐句核对

- 每一句剧本台词对应一个条目，左侧数字为行号。
- 绿色边框：该句所有短语均在字幕中找到。
- 红色边框：该句存在缺失短语，并在标签中列出缺失内容。
- 下方短语标签：绿色背景表示已找到，红色背景表示缺失。

### 5.2 字幕行覆盖情况表

- 表格列出每行字幕的原文、状态、匹配到的剧本短语。
- 状态“✅ 被剧本覆盖”：该行字幕至少匹配到一个剧本短语。
- 状态“⚠️ 多余”：该行字幕未匹配到任何剧本短语，可能为多余或错误内容。

## 七、常见问题（FAQ）
Q1：为什么有些台词没有被提取？
A：请检查台词是否以“人物名：”开头，且冒号后紧跟内容。集数行、场景行、元信息行会被自动过滤。

Q2：为什么某些短词总是显示缺失，即使字幕里有？
A：短词（≤2字）采用严格边界匹配，例如“是”不会匹配“是否”。若确需匹配，请将短语长度调整为≥3字，或修改代码中的 normPhrase.length <= 2 判断条件。

Q3：可以保存核对结果吗？
A：目前不支持导出，但您可以手动复制结果区域内容，或使用浏览器打印功能（Ctrl+P）保存为 PDF。

Q4：数据会上传到服务器吗？
A：不会。所有处理均在本地浏览器中完成，无任何网络请求。

## 十、扩展建议
若需要支持更多台词格式，可修改 extractLines 函数中的正则表达式。

若需要调整匹配严格程度，可修改 hasPhraseMatch 中的长度阈值和边界判断逻辑。
